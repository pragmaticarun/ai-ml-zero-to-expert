Interactive weekly quiz (12 questions)

Q1.

Name four things a run record must contain.

Any four of: data hash, config, metric, library versions, commit, timestamp, artefact path.

Q2.

What was the 5-seed AUC spread on Day 57, and what does it imply for model comparisons?

Std 0.0008 (mean 0.9286). Differences under about 0.002 are not distinguishable.

Q3.

Why verify predictions after a joblib round trip?

To confirm the saved pipeline reproduces the original predictions exactly.

Q4.

Which capstone model won CV, and was the margin meaningful?

hist_gb_tuned (0.9280 vs 0.9277), well within the std of 0.003. Not meaningful.

Q5.

What threshold met precision ≥ 0.70, and did it hold on test?

0.3778. Test precision was 0.7026, so yes, narrowly.

Q6.

Give the test AUC and its bootstrap CI.

0.9291, [0.9237, 0.9331].

Q7.

Which fairness criterion roughly held across sexes, and which did not?

Predictive parity (precision 0.708 vs 0.702) roughly held. Equal opportunity did not (recall 0.661 vs 0.774).

Q8.

Why does the perceptron fail on XOR?

XOR is not linearly separable.

Q9.

Maximum of the sigmoid derivative?

0.25, at z = 0.

Q10.

Parameter count of 64→32→10?

2,410.

Q11.

What happened to the activation std after 10 ReLU layers with std-1 init?

It exploded to about 1.5e7.

Q12.

Write dZ2 for softmax plus cross-entropy, and state the gradient-check pass criterion.

dZ2 = (P − Y)/m. The check passes when the relative error is below about 1e−7 (ours was about 1e−10).

Week overview, goals, project and quiz text

Week goals

  1. Make an experiment reproducible: seeds, a data fingerprint, a config, model persistence and a run log.
  2. Build, evaluate and report the Month-2 capstone: a complete tabular ML project with an honest single test evaluation, calibration, slice analysis and a model card.
  3. Pass the Month-2 checkpoint exam (six self-graded code exercises).
  4. Start Month 3: perceptrons, forward propagation, and a NumPy MLP trained with hand-derived backprop.
