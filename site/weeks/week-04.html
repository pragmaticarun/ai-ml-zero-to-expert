Interactive weekly quiz (12 questions)

Q1.

Write the linear-regression cost J(w, b).

J = (1/2m) Σ (wxᵢ + b − yᵢ)².

Q2.

Give the GD updates for w and b.

w ← w − α·mean((ŷ − y)x) and b ← b − α·mean(ŷ − y), updated simultaneously.

Q3.

J rises during batch GD. Name two possible causes.

α too large, a gradient sign bug, unscaled features (or a non-simultaneous update bug).

Q4.

Shapes: X is (m × n). What shapes are w, Xw and Xᵀe?

(n,), (m,), (n,).

Q5.

Why scale features before GD? Give the z-score formula and say what to fit it on.

It makes the cost bowl round (better conditioned), so a single α works and convergence is fast. x′ = (x − μ)/σ, with μ and σ from the training data only.

Q6.

What iteration counts and condition numbers did you measure, raw vs scaled?

Raw data hit the 200,000 cap (or stopped early, far from the optimum). Z-scored data converged in 83 iterations. κ was 9.63e4 vs 1.16.

Q7.

Write the sigmoid and the log-loss.

σ(z) = 1/(1 + e^(−z)). L = −[y log p + (1 − y) log(1 − p)].

Q8.

What is the logistic-regression gradient form?

∇_w = Xᵀ(p − y)/m and ∂b = mean(p − y).

Q9.

TP = 30, FP = 10, FN = 20. Precision, recall and F1?

P = 0.75, R = 0.6, F1 = 0.667.

Q10.

Train MSE 0.04, val MSE 0.14, noise floor 0.09. Diagnosis and two fixes?

Overfitting (variance). Get more data, add regularisation, or use a simpler model.

Q11.

What does ROC-AUC = 0.5 mean?

No better than random ranking.

Q12.

What did error analysis reveal in the Day-28 project, and what was the fix?

Homes over 1800 sq ft were under-predicted (+5.31 mean residual). Adding a hinge feature max(area − 1800, 0) brought RMSE from 6.375 to 6.171.

Week overview, goals, project and quiz text

Month 1, Foundations. Time budget: 42 h. Optional reading: the scikit-learn user guide sections on linear models and model evaluation (https://scikit-learn.org/stable/user_guide.html), and An Introduction to Statistical Learning, ch. 3-4 (https://www.statlearning.com/).

Week goals

  1. Frame supervised learning as model + cost + optimiser, and visualise the cost surface J(w, b).
  2. Implement batch gradient descent for linear regression and read learning curves.
  3. Vectorise to many features, and match the normal equation and scikit-learn to 4 decimals.
  4. Explain why feature scaling speeds up GD (conditioning), and measure it.
  5. Implement logistic regression with log-loss, and match scikit-learn.
  6. Evaluate classifiers properly (confusion matrix, precision/recall/F1, thresholds, ROC-AUC) and diagnose bias vs variance.

Weekly project (Day 28): an end-to-end housing regression with error analysis, finding which homes the model gets wrong and fixing it with one feature.

flowchart LR
  D[data X,y] --> S[split + scale on train only] --> M[model f_w]
  M --> C[cost J]
  C --> O[gradient descent]
  O --> M
  M --> E[evaluate on held-out set]
  E --> A[error analysis → next idea]

All Week-4 scripts use code/week-04/housing.py, a deterministic synthetic generator. The true rule is price (lakh) = 0.05·area + 4·beds − 0.4·age − 0.8·dist_km + 20 + noise(σ = 6). Because we know the truth, we can check whether our learners recover it.
