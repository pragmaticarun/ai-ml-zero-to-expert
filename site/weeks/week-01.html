Interactive weekly quiz (12 questions)

Q1.

Name the three ingredients of an ML learning procedure.

Model family, cost function, search/optimisation.

Q2.

MSE for predictions [2, 4] against targets [1, 6]?

((1)² + (−2)²)/2 = 2.5.

Q3.

Shape of (7, 1) − (7,)?

(7, 7), an accidental broadcast.

Q4.

Which is a view: M.T, M[[0, 1]], M[:, ::2]?

M.T and M[:, ::2] (basic slicing). Fancy indexing M[[0,1]] copies.

Q5.

Why is a Python loop dot product hundreds of times slower than np.dot?

Per-element interpreter overhead (boxing, dynamic dispatch) vs compiled, SIMD, BLAS loops.

Q6.

State the identity used to compute all pairwise squared distances with one matmul.

‖p−q‖² = ‖p‖² + ‖q‖² − 2p·q, so all pairs are norms plus −2PQᵀ.

Q7.

Why one-hot encode city rather than using codes 0/1/2?

Integer codes impose a fake order and spacing. One-hot gives each city its own coefficient.

Q8.

What does a U-shaped residual plot mean, and what is the fix?

The model is too simple (missing non-linearity). Add features such as x², or use a more flexible model.

Q9.

What is the validation set for, and what is the test set for?

Validation is for choices and tuning. Test is used once, for an honest final estimate.

Q10.

In the leakage demo, why did "select features on all rows" give positive test R² on pure noise?

The selection used chance correlations that included the test rows, so they "held up" on those same rows.

Q11.

What MAE did "predict the mean" get in the Day 7 run, and which baseline won?

16.96 lakh. The line on area won (8.77).

Q12.

int8: what is 100 + 120?

−36 (wrap-around), with an overflow warning.

Week overview, goals, project and quiz text

Month 1, Foundations. Time budget: 7 days × 6 h = 42 h.

Week goals

By the end of this week you can: 1. Explain in one sentence what "learning" means in ML: choose parameters that make a cost small on data. 2. Use NumPy arrays fluently: shapes, dtypes, indexing, views vs copies, broadcasting. 3. Write vectorised code, and explain why it is about 100-1000× faster than a Python loop (interpreter overhead, SIMD, BLAS), using the same mental model you use for C++/Rust. 4. Load, clean and summarise a table with pandas, and turn it into a model-ready matrix. 5. Make the three EDA plots you will use for six months: histogram, scatter, residual plot. 6. Split data into train/validation/test reproducibly, and recognise data leakage.

Weekly project (Day 7): an EDA report on a synthetic housing table plus three baselines, each scored by test MAE.
