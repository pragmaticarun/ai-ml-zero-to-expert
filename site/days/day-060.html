Block 1: Capstone delivery checklist (1h)

Your capstone is done when a stranger could clone the repository and get your numbers. Check each item: 1. README.md gives the problem, how to run it (one command), and the expected outputs. 2. Running from scratch regenerates cv_table.csv, the model and report.md with the same numbers. Run it twice and diff the outputs. 3. The model card covers the data hash, config, versions, metrics with CIs, intended use, out-of-scope uses, slice results and limitations. 4. The test set was used once, and the report says so. 5. Every number in the report comes from a file the code wrote. Nothing is copied by hand.

Capstone rubric (self-grade out of 30):

criterion points
Clean, leak-free pipeline; test touched once 6
Baselines and ≥ 4 candidates compared with CV mean ± std 5
Threshold chosen on CV for the stated business constraint 3
Test metrics with bootstrap CIs; constraint checked 4
Calibration assessed (table or plot plus Brier) 3
Slice analysis with n, CIs and an honest discussion 5
Reproducible: one command, same numbers twice, model card 4

24+ is excellent, 18-23 is solid (fix the gaps this week), and below 18 means you should redo the weakest sections before Month 3.

Block 2: Checkpoint exam: code (1h15)

code/week-09/day60_checkpoint.py holds six exercises with automatic checks. Write each function yourself in a fresh file, without notes, and then run the checks against your versions. (The reference solutions inside the script are for after you're done.) 1. Ridge regression closed form, matching sklearn.linear_model.Ridge. 2. K-fold index generator, matching KFold. 3. Gini impurity (gini([0, 0, 1, 1]) = 0.5, and a pure node = 0). 4. One k-means step that does not increase inertia. 5. Rank-based ROC-AUC, matching roc_auc_score. 6. PCA via SVD: uncorrelated components with descending variance.

The reference run passes 6/6. Target: 5/6 within 75 minutes.

Block 3: Checkpoint exam: concepts (1h)

Answer in writing, in at most five sentences each: 1. A colleague reports 0.97 accuracy on a fraud dataset with 1% fraud. What three questions do you ask? 2. Explain why shuffled CV failed on the bike data (Day 53), with the numbers. 3. Bias or variance? Train error 0.0, val 0.19, and the curve is still decreasing (Day 55). What next? 4. Why did Platt scaling leave AUC unchanged but fix the Brier score? 5. Random forest vs gradient boosting: what does each reduce, and how? 6. Your clustering silhouette says k = 3 but the domain expert says 4. How do you proceed? 7. When is anomaly detection preferable to supervised classification? 8. In the capstone, the tuned model "won" by 0.0003 AUC. Write the sentence you'd put in the report.

Grading: compare your answers with the relevant lesson's Block 1 and the quizzes. Give 2 points for each answer that includes the key idea and a number from our runs where one applies.

Going deeper (optional)

Publish (privately, or publicly if you like) your capstone as a short write-up: the problem, the approach, the honest results and the slice findings. Explaining it to someone else is the best test of understanding. This is optional and entirely your call.

Interview-style question (15 min, written)

Before you close Month 2, write a half-page answer to: "Walk me through your capstone in three minutes." Use this structure: - problem and constraint (precision ≥ 0.70), - data and its caveats, - how you avoided leakage, - what CV said and how much the differences meant, - the one-shot test result with its interval, - the slice finding you would raise with a stakeholder, - what you would do next with two more weeks (informed by the Day 55 diagnosis).

Read it aloud and time yourself. If it runs over, cut detail, not caveats. Keep this script. It becomes your portfolio summary.

Common mistakes / how to debug

  • Skipping the reproducibility re-run because "it worked last time".
