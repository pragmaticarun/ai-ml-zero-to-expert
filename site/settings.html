Sync across computers (optional)

Status: Not connected

  1. Create a classic GitHub token with only the gist scope: github.com/settings/tokens/new?scopes=gist. Choose an expiry, then copy the token.
  2. Paste it below and press Connect. The site looks for an existing secret gist named aiml-course-progress.json and reuses it. If there isn't one, it creates a new secret gist.
  3. Do the same once on each computer, using the same GitHub account. Progress is merged, not overwritten.

What is stored where, and how to revoke
  • This browser (localStorage): your progress, the token (key aiml-sync-token) and the gist id. The token is never included in exports or the progress file. It is only ever sent to api.github.com.
  • Your gist: progress only (checked blocks, hours, notes, quiz answers and marks, flashcard schedule, start date, theme). It is secret: unlisted and not searchable. However, anyone who has its URL can read it, so don't put anything sensitive in your notes.
  • Keep the token private. It can read and write all of your gists. Use a separate token for this site.
  • Disconnect removes the token and gist id from this browser only. Your progress and the gist stay as they are.
  • Revoke the token at github.com/settings/tokens. You can delete the gist at gist.github.com.
  • Sync runs about 2.5 s after each change, when a page loads, and when you return to the tab. While you're offline, changes are kept here and synced later. If the same item is changed on two computers, the most recent change wins.

Backup

Static, offline site. Progress is saved in this browser; optional sync to your own private GitHub Gist (Settings → Sync). Export to back it up.
