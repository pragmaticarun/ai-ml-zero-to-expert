# Data

Nothing large is committed. Month 1 needs **no downloads**:
- Synthetic housing data is generated by `code/week-04/housing.py` and `code/week-01/day04_pandas_basics.py` (seeded, deterministic). It is invented for teaching and is not real market data.
- `load_digits` and `load_breast_cancer` ship inside scikit-learn (https://scikit-learn.org/stable/datasets.html).

Later months use the downloaders in `download.py`, which cache files to `data/cache/` (git-ignored):
- California housing (`sklearn.datasets.fetch_california_housing`), Month 2
- MNIST / CIFAR-10 via torchvision (https://docs.pytorch.org/vision/stable/datasets.html), Month 3
- Hugging Face datasets (https://huggingface.co/datasets), Month 4
- UCI repository (https://archive.ics.uci.edu/), Month 2 projects

`bash run_all.sh` downloads any missing ones on first use (through `code/common.py`).

Month 3 datasets (fetched and verified on this box; cached under `data/` or the torch cache on first use):

| dataset | used on | source |

Why OpenML for CIFAR: the original CIFAR-10 tarball host was unreachable from this box when Month 3 was built, so the course uses the OpenML 20,000-image version. Results are therefore not comparable with full-CIFAR-10 numbers in papers.

Month 5-6 data (Weeks 18-22). Nothing new is downloaded: RL environments are built in code or come from Gymnasium (installed by pip; docs https://gymnasium.farama.org/ ); Week 21 uses scikit-learn's bundled Wisconsin breast-cancer table; Weeks 20 and 22 reuse SmolLM2-135M-Instruct (above) and the course's own `weeks/*.md` as the retrieval corpus (Day 150 indexes Weeks 1-16; Day 154 also tiles it 64x in memory to 70,336 chunks). Eval cases, attacks and drift queries are hand-written in the scripts. Generated files (prompt registry, generation cache, traces) are written to `code/week-22/out/`.

Month 6 capstone closeout (Weeks 25-26, Days 169-180). No new public datasets. The Course Assistant indexes this course's own `weeks/*.md` (**1467** chunks) with MiniLM embeddings cached under the local HF cache / `code/capstone/out/`. Generator weights are SmolLM2-135M-Instruct (same Hub id as Month 4). Eval QA pairs, injection strings, and ablation toggles live in `code/capstone/` and `code/week-26/`. Freeze scorecards: `code/capstone/out/freeze/`. Android / GPU artefacts remain UNTESTED and must not be described as measured on a phone or GPU.
